> Blending the agile Socratic craftsmanship of Matt Pocock with the compounding institutional memory and industrial rigor of Compound Engineering.

## 🌟 Vision & Philosophy

AI 编码 Agent 正在重塑现代软件开发，但现有的工程体系往往走向两个极端：
* **过于散装或过度依赖单轮心流**：缺乏系统化沉淀，跨 Session 即遗忘（踩过的坑一踩再踩）。
* **过于沉重或过度包装**：层层转译、仪式感冗余、上下文窗口被过度的参考文件迅速占满。

**NexusKit (`nk-*`)** 应运而生。它提取自真实高强度实战项目的深度复盘与迭代，旨在实现：
1. **人机心流与苏格拉底对齐（Socratic Grilling）**：不盲目狂奔，通过前沿决策树（Frontier Tree）消除隐性假设。
2. **严苛的工程纪律（Disciplined Craftsmanship）**：排错绝不凭空猜测，先建秒级变红反馈循环（Tight Red-capable Loop），测试先行（TDD）。
3. **经验复利与认知记忆（Compounding Memory）**：沉淀可复用的解决方案与领域术语词典（`solutions/` & `CONCEPTS.md`），使每个单位的工程工作都比上一次更容易。
4. **统一前缀与极简输入（Ergonomic Prefix）**：全套技能统一采用键盘手感极佳的双字母前缀 **`nk-`**，杜绝命名污染，呼出极其流畅。

## 🧩 技能体系全景架构 (Preview)

NexusKit 规划以下几个核心模块矩阵：

| 模块 | 核心技能示例 | 定位与核心价值 |
| :--- | :--- | :--- |
| **对齐与探索 (Align & Explore)** | `nk-grill`<br>`nk-brainstorm`<br>`nk-wayfinder`<br>`nk-wait-what` | • 决策树深度追问，剥离迷雾与认知盲区<br>• 提炼领域统一语言与需求骨架<br>• 即时刹车与极简技术澄清 |
| **设计与规划 (Design & Plan)** | `nk-plan`<br>`nk-pov`<br>`nk-doc-review` | • 契约式统一执行计划（Unified Plan）<br>• 架构决策交叉评审与多视角论证 |
| **编码与执行 (Build & Craft)** | `nk-work`<br>`nk-tdd`<br>`nk-prototype`<br>`nk-wizard` | • 严格测试先行（Red-Green-Refactor）<br>• 交互式向导脚本生成与抛弃型原型探索 |
| **诊断与质量 (Diagnose & Quality)**| `nk-debug`<br>`nk-code-review`<br>`nk-simplify` | • 5 阶段因果链溯源 + 严苛反馈闭环<br>• 防腐化精简与回归防护 |
| **经验复利 (Compound Memory)** | `nk-compound`<br>`nk-compound-refresh` | • 解决非平凡难题后的经验萃取入库<br>• 过时/冲突经验的定期巡检与刷新 |
| **交付与流转 (Ship & Flow)** | `nk-commit`<br>`nk-handoff` | • 高语义 Git Commit 组织<br>• 零损耗跨 Agent 会话接力 |

## 🚀 安装与使用

本仓库作为技能集直接配置于 Agent 环境（如 Antigravity / Claude Code / Codex / Cursor 等）。

所有的命令均以 `/nk-` 开头呼出，例如：
```text
/nk-grill        # 围绕模糊需求对用户展开前沿追问
/nk-debug        # 启动严苛的五阶段因果排错循环
/nk-compound     # 将解决后的非平凡问题沉淀为持久化学习文档
```
